RIMWORLD 1.6 - SHUTTLE TYPES AND PROPOSED VERTIBIRD MAPPING
============================================================

Audit date: 24 July 2026

Scope
-----
- RimWorld Core and all five official DLCs
- every locally installed Vanilla Expanded mod
- Rimsential - Spaceports (Continued), packageId zal.spaceports
- the installed FCP Brotherhood of Steel, Enclave, and Tools mods

This is a catalogue and design proposal only. It does not yet change any Def.

Terminology
-----------
"Type" means a visually or functionally distinct craft. Incoming, leaving,
crashing, landed, and world-map Defs belonging to the same craft are listed
together and are not falsely counted as separate vehicles.

"Functional" means that the object participates in a shuttle/transport system.
"Crash only" means an encounter and wreck with no normal usable craft.
"Decorative" means a prop or ruin.

- ShuttleC -> Skip east

5. PROPOSED FALLOUT MAPPING
===========================

This mapping preserves recognizable roles instead of assigning one identical
image to every craft.

Vanilla and DLC
---------------
- Standard / Imperial Shuttle -> Enclave vertibird
  Reason: Empire is already Whitespring Enclave in FIP.
- Crashed standard shuttle -> crashed Enclave vertibird
- Mechanitor ship -> Tools gunship vertibird
- Crashed Mechanitor ship -> destroyed pre-war Army vertibird
- Passenger shuttle -> Tools light vertibird
- Ancient rusted dropship -> destroyed pre-war Army vertibird
- Ancient dropship engine -> FCP vertibird-engine artwork or a dedicated
  destroyed-engine crop, not a complete vertibird body

Vanilla Events Expanded
-----------------------
- Standard crashed shuttle -> crashed generic/BoS vertibird
- Combat crashed shuttle -> crashed Tools gunship
- Heavy crashed shuttle -> crashed Tools cargo vertibird

VFE Empire and Deserters
------------------------
- Imperial shuttle skin -> Enclave vertibird
- Armored Imperial shuttle -> Enclave vertibird or Tools gunship; replace or
  remove VFEI_TurretArmoredShuttle as part of the same patch
- Deserter / Circle of Steel shuttle -> Brotherhood Outcast vertibird

VE Props
--------
- Personal pod -> light vertibird, reduced drawSize
- Superpod -> light vertibird
- Skip -> light vertibird
- Spacer shuttle -> standard Brotherhood vertibird
- Albatross gunship -> Tools gunship vertibird
- Heavy dropship -> Brotherhood or Enclave vertibird
- Heavy cargo shuttle -> Tools cargo vertibird
- Ancient shuttle -> destroyed pre-war Army vertibird

Spaceports
----------
- RoyaltyShuttle -> Enclave
- A -> generic light
- B -> Tools gunship
- C -> generic light
- D -> standard Brotherhood
- E -> Brotherhood Outcast
- F -> Lyons' Pride
- G -> Tools cargo
- H -> Enclave
- I -> generic light
- J -> Brotherhood
- K -> Tools gunship
- Skip -> generic light
- Superpod -> generic light
- Inert -> destroyed pre-war Army vertibird
- Surprise -> damaged generic light vertibird

The repeated families are intentional: Spaceports has more logical visitor
variants than FCP currently has unique silhouettes. Faction skins and drawSize
can preserve variety without inventing unsupported new art.


6. IMPLEMENTATION RULES FOR A LATER PATCH
=========================================

1) Patch every rendered state
   A complete replacement must include landed ThingDef, Incoming, Leaving,
   Crashing, crashed wreck, TransportShipDef shipThing link where necessary,
   and any shuttle-specific world icon.

2) Do not replace shared world resources globally
   Spaceports uses generic Caravan/TravelingTransportPods resources. Patching
   those globally would alter unrelated caravans and transport pods.

3) Normalize Graphic_Multi deliberately
   PassengerShuttle and several VE Props expect direction suffixes. The FCP
   Tools craft point directly to an east image. Either:
   - replace graphicClass with Graphic_Single and use the FCP east image; or
   - create proper north/east/south FCP variants and retain Graphic_Multi.
   Graphic_Single is the safe first implementation.

4) Preserve or deliberately flatten FCP Graphic_Random
   Standard Brotherhood and Enclave Vertibirds use Graphic_Random directory
   paths. A target Def must either keep Graphic_Random and point to the folder,
   or use Graphic_Single and point to a concrete file. Combining a random
   directory path with Graphic_Single will produce a missing texture.

5) Patch VFE's armored-shuttle turret separately
   Otherwise an Imperial autocannon remains floating above a Vertibird.

6) Patch Spaceports last
   Its VE Props compatibility redirects six bodies. The Fallout replacement
   must load after both Spaceports and Props and Decor.

7) Keep body and footprint compatible
   A texture change does not alter size, interaction cell, shadow, drawSize, or
   landing footprint. Each mapped Vertibird needs a visual in-game check.

8) Recommended ownership
   The broad "replace every non-Fallout shuttle" layer fits FIP-Donaustahl as
   optional immersion-overhaul content. Faction-native craft can remain in the
   individual FIP/FCP compatibility folders.
