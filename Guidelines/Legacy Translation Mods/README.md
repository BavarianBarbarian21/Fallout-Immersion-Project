# Legacy translation mods

These translation packages belong to the pre-1.0 translation workflow. They
are retained for terminology reuse and migration history, but they are not the
source of truth for new releases.

The 1.0 workflow uses `FIP-Yes Man` to generate a complete, internal
`FIP - English Language Pack` from the final loaded game state. New language mods are
created as working copies of that English source and then translated.
